# reelson

**reelson** turns a prompt into a finished, branded demo video of your web app. It is two Agent Skills and a CLI for Claude Code, Codex or any agent that reads skills: a Playwright walkthrough with a human-paced cursor, then a HyperFrames composition with an intro, callouts, zooms and an outro. When the UI changes, the same prompt records the video again.

<a href="https://github.com/reelson/reelson"><img src="https://github.com/reelson/reelson/releases/download/demo/demo.webp" alt="A reelson demo video: branded intro, a task added and dragged to Done in a zoom, outro" width="100%"></a>

```bash
npm install -g reelson
reelson install
```
